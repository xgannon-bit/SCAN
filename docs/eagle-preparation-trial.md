# Copied-job preparation qualification

Fresh symmetric models can require an independent, source-hash-bound four-edge
body datum and manufacturer bounds. An explicit `targetSourcePaths` override
selects the fresh constructor for those source scopes; it does not borrow the
competing template's offsets. Other scopes and saved profiles retain their route.
A reviewed CAD import quantum can account for at most one quantum of translation
residual between rounded CAD controls. It is bounded to 0.001 mm, requires the
independent body datum and exact on-quantum CAD literals, and never moves CAD.

Review/apply generates `offline-binding-fov-intents.json`. Fresh constructed
terminal windows are checked against their exact source pad path, number, pin
map and geometry. Body references, absent physical leads and underside pads do
not acquire binding intents. Template windows require their own pad mapping.
Window coverage extents are calculated in the explicitly unqualified native
frame hypothesis. FOV/image membership and native Gerber artwork are not inferred
from proximity, counts or dimensions. Native binding/FOV fields stay empty.
Project reopening rebuilds these plans from verified original inputs and profiles.

## Operator trial

Use the private delivery's original control and smallest representative candidate,
not the full candidate for the first test. All operations are on disposable job
copies with job-local models. Record Eagle build and Athena identity. Menu labels
and the way to teach a disabled model are **unverified**; these are task names,
not verified menu paths. Stop if conversion, library/model synchronization, silent
snapshot substitution or enabling is required; capture that prompt.

1. Open the selected main of an unchanged original copy. Save and reopen it;
   retain the saved whole-job copy as the no-edit normalization control.
2. Open/save/reopen the trial without edits. Verify the supplied exact Part,
   reference, module and Master identities and every body/terminal window.
3. On the fresh two-terminal representative, bind **one** numbered owned land
   to its terminal window. Save/reopen as a separate stage. Bind the second only
   after that stage is recorded. Do not globally rematch or use shared libraries.
4. Assign one representative to an existing suitable FOV, save/reopen separately.
   Inspect complete window coverage, image origin and multi-FOV requirements.
5. Teach one required image-dependent feature in place, save/reopen separately.
   Keep the trial disabled. Compare placement/CAD/origin/angle and local windows
   after each stage; moving a window or model origin must not hide a position loss.
6. Repeat geometry/binding checks on each supplied distinct structural class and
   source orientation. Assess physical visibility before teaching external joints;
   no absent-lead or underside thermal optical inspection is authorized.

Return the exact build/operation sequence and private saved job copies for the
control and each stage, plus a selected-identity/numbered-pad screenshot if fields
remain ambiguous. No replacement PCB/CAD/BOM is needed for this trial.

## Read-only returned-copy comparison

The local CLI records selected identities, placement/CAD/model/window numeric
retention, binding/FOV deltas, every changed native record scope and archive member.
It never writes a job or grants qualification. No-edit normalization, image geometry,
semantics, unintended scope and actual inspection still require engineering review.

```powershell
.venv\Scripts\python.exe -m workers.scan.eagle_trial_compare `
  --before BEFORE.zip --after AFTER.zip `
  --selection snapshot-selection.json --targets trial-identities.json `
  --stage one-binding --eagle-build "EXACT BUILD" --output comparison.json
```

Outputs must stay private. The comparison file must be new. Preserve separate
before/after copies, Temp and backups; do not substitute their original state for
the edited main. Qualifying opening alone does not qualify binding, teaching,
position retention, defect detection, population, enabling or release.
