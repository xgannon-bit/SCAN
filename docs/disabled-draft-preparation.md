# Disabled draft preparation status

The Review screen now derives family preparation from original ACCEL PCB bytes
and the selected native baseline. It does not create native records for a real
board. Save project retains the original inputs; reopening reparses the layout
and rebuilds the family review. The downloaded review is evidence, not a job.

## Source evidence available

The reader separately reports explicit numbered-layer Rect, Oval and circular
Ellipse outlines, pad ownership, local/board centers, pad/placement rotations
and drill evidence. Unknown layer-class rules remain unresolved. A complete
explicit layer does not mean a complete pad stack, paste layer, inspection side
or native coordinate registration. Full-geometry holds are retained.

The first geometric family is two equal, separated rectangular pads with the
same cardinal orientation on a source-local row or column and explicit zero
hole diameters. Reference prefixes and footprint names do not select this family.
Hole-bearing placements are separate work, not automatic inspection exclusions.
Existing native structure and engineering DNP retain their separate review holds.

Literal package-name correspondences to selected local Masters show linked
placements and window counts. They do not establish model compatibility.
Native ROI, Master windows, source centers and explicit layer outlines are shown
in separate frames. No overlay or binding is inferred.

## Structural writer implemented, real template adapter incomplete

`workers/scan/disabled_draft.py` has a typed, source-derived recipe and a narrow
two-pad structural profile. It checks exact source hashes, existing native CAD
scope, absent target placement, disabled template state, unique Master selection,
zero template offset and exact local pad/window correspondence. It refuses
unknown template fields, algorithms, linked windows, unresolved layer-class
rules, holes, unsupported geometry, duplicates and repeated application.

New IDs reserve observed identity/reference numbers across both documents.
The recipe contains every complete inserted record and its dependencies.
Apply re-derives the recipe from original bytes and compares its reviewed digest.
It appends a new disabled placement, independent local Master and two disabled
windows. Algorithms are empty; source CAD, existing teaching and opaque original
XML bytes are preserved. This is not taught inspection.

`disabled_draft_package.py` freezes a hash-verified archive, requires explicit
main job/main Master selections, preserves other entries and ZIP metadata,
independently reopens and hashes the candidate, and publishes a new isolated
transport atomically. Failure leaves no partial package. Temp/backup snapshots
retain their original state and must not be substituted in a later trial.

**This profile is proven only on wholly authored synthetic structures.** Actual
observed native templates contain additional settings, references and image
dependencies outside this contract. They remain refused. The trial translation
is an explicit hypothesis, not a qualified source-to-Eagle transform. The
structural writer has no browser export endpoint and cannot expand the existing
scalar trial approval. The current app's real candidate export remains the
previous separately reviewed scalar route.
