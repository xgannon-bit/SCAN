## Repair three different things separately

Source-family review now connects to complete disabled native part preparation.
The job-local same-footprint adapter derives a new placement, local Master and
linked windows from a compatible source-owned template using the native CAD frame.
Individual review/apply, complete candidate transport, actual candidate accounting,
remaining native work and saved decisions/history are integrated. Exact owned
source geometry can support translation or a strictly witnessed cardinal rotation;
unqualified origins, rotations and missing template families remain held. A closed
window subset can prepare a partial model when external dependencies are excluded
with their affected groups and dependents. Exact omissions remain unfinished Eagle
work, never approved exclusions. Component-by-component exports use freshly parsed
candidate placements, Masters, windows and binding diagnostics. Pad ownership and
native/source frame qualification remain held; new bindings/FOV lists and algorithms
remain empty. Eagle compatibility and teaching are unverified.
See [disabled native preparation](disabled-draft-preparation.md) for the exact
contract and qualification boundaries.

An explicit reviewed manufacturer profile can also construct a missing symmetric
two-terminal body and owned terminal-land reference model without an identical
native footprint template. Review/apply, complete transport, source-derived window
roles and current/historical profile persistence are integrated. New models remain
disabled with no algorithms or bindings. Drawing matches are reviewed inputs;
native local-frame interpretation, model metadata and teaching remain unverified.
See [paired-terminal construction](paired-terminal-construction.md).

1. Source-format defects: combined X/Y columns, numeric text, explicit unit conversion, coordinate-format declarations and revision inconsistencies.
2. Cross-file alignment: side, origin, units, angle convention, mirror and module transforms, with independent correspondences and residual checks.
3. Job model defects: duplicate enabled placements, displaced ROIs, dangling relationships, incorrect component-pad associations and inconsistent template reference origins.

Do not move correct CAD to compensate for a misplaced job ROI. Do not rewrite a correct Gerber when the defect is a window's pad association. Native footprint origin, pad-pattern midpoint and optical body center are distinct.

## What can be derived from which input?

| Input | Defensible output | Missing evidence / limits |
| --- | --- | --- |
| Complete supported native PCB layout | Placement export; layout-derived pad/reference layers; native-tool manufacturing exports where actual layers exist | Verify side, revision, population, origin, layer semantics, tool support and independent output comparison |
| Placement file + exact footprint library | Draft placed footprints and AOI reference-pad geometry | A library land pattern is not automatically the approved paste/stencil layer; validate identity, orientation and actual artwork |
| Gerber + assembly drawing + BOM | Cross-check geometry and manually reviewed component association; enriched formats may supply more metadata | Ordinary paste-only Gerber need not contain reference names, MPNs or body origins; no nearest-pad-only assignment |
| Calibrated board scan + dimensional/assembly evidence | Proposed component locations and draft inspection geometry | Account for distortion, occlusion, side, scale and identity; no hidden layers or precise solder limits inferred from a photo |
| Schematic + BOM only | Component/connectivity inventory and missing-source checklist | Not the existing PCB's physical locations, routing, paste, fiducials or panelization |

A schematic may support designing a NEW PCB with explicit layout, routing and engineering decisions. It does not uniquely reconstruct an EXISTING manufactured PCB. That separate ECAD design workflow is outside the first alpha.

## Output classes

- Normalized placement candidate: traceable to supplied source coordinates and confirmed unit/convention rules.
- Derived AOI reference layer: clearly labeled NOT FOR FABRICATION; pad geometry is not automatically paste geometry.
- Manufacturing regeneration: only from authoritative, complete layout/layer data through a supported native exporter and engineering approval.
- Machine job candidate: separate copy with reviewed exact edits, adapter tests and machine compatibility gates.

## Release boundary

BOM/stage exclusions remain provisional until approved. New layouts are not taught optical inspections. No automatic threshold relaxation, guessed OCR identity, polarity approval or product release.

## Engineering intake checkpoint

The primary progression is Import → Review → Export, with specialist screens retained. Header candidates are shown for CSV metadata preambles. Legacy Windows-1252 and recovery of malformed quotes in a final Description field require explicit selection; defaults refuse those inputs. Recovery never rewrites original bytes or other columns.

Gerber holds identify the source line, command, offending token and declared capacity. A width-only interpretation hypothesis preserves declared decimals; it neither selects an override nor assumes missing interpolation. Source-to-source median-translation diagnostics separate fit and held-out references. These are unqualified origin hypotheses, never native transforms or confirmed local defects.

Candidate transport now includes source reconciliation and source geometry evidence beside the native engineering ZIP and saved project. Baseline evidence remains explicitly baseline evidence. Generation receipts do not claim a browser download was saved; actual disk download/reopen is a separate evaluation check.

Reviewed package evidence supports a three-physical-terminal constructor with separate anode, cathode and electrical no-connection roles. A numbered manufacturer drawing must match every owned land, and four explicitly selected owned graphic edges must close a body rectangle within the drawing's dimensions. Clearance rectangles, markings, mirrored pin arrangements and stale source evidence refuse writing. The constructor appends a disabled job-local placement, Master and body plus three terminal reference windows; it adds no algorithms, bindings or FOV assignments. Review/apply, complete-job export and project reopening retain exact profiles and decisions. Electrical NC remains a physical lead, not an inspection exclusion. Native frames, polarity teaching, binding retention and Eagle compatibility still require machine-side qualification.

A reusable numbered physical-terminal constructor separates physical package leads from extra footprint lands. Each absent lead requires explicit matched manufacturer evidence; pin 1 requires source-bound orientation evidence. Every physical electrode must match its owned numbered land after the reviewed cardinal package transform. The body datum uses four owned rectangle edges within manufacturer bounds. Extra lands remain in source accounting, with no invented physical-lead window, binding or exclusion. New job-local records are disabled and untaught. Review/apply, complete native export and project reopening preserve exact profiles, absent-land evidence, decisions and candidate history. Pin-1 marking, native frames, pad bindings, FOV, image teaching and Eagle open/save/reopen remain qualification work.

External-terminal/thermal-pad preparation requires a matched numbered package drawing and source-owned geometry for every external terminal and underside pad. Explicitly selected three-sided or closed cardinal body frames must fit manufacturer bounds; clearance, disconnected lines and marking graphics cannot establish the datum. Numbered pin 1 is source-bound. New disabled local models contain body and external-terminal land references only. Underside thermal pads remain separately accounted geometry without a native optical window, binding or inspection exclusion. External joint visibility remains unknown; geometry never proves optical access. Saved projects, candidate history and complete native exports retain this distinction and exact remaining work. Hidden-joint coverage needs a separate inspection method or approved coverage decision before enabling; machine qualification and image teaching remain pending.

Fresh symmetric two-terminal preparation can corroborate the manufacturer's body
datum with exact owned body edges, bypassing an explicitly selected inconsistent
template route without borrowing its offsets. Bounded, reviewed CAD import
quantization does not move coordinates. Review/apply and reopening rebuild exact
owned-pad/window binding intents and hypothesized window coverage extents; native
binding and FOV assignment remain held. A read-only controlled Eagle trial
comparison reports identity/position, binding/FOV and unrelated-record/asset
changes without granting qualification. See [the trial guide](eagle-preparation-trial.md).
