# Copied-job output status

The intended result is a complete native engineering candidate, with approved
changes, preserved teaching, per-component accounting and a precise machine-side
work queue. A report or preserved original is not that result.

## Implemented engineering increments

- Explicit job/master selection, immutable archive capture and verification of
  every archived file. Main, temporary and backup selections remain distinct.
- Bounded literal native reading, including saved pads and algorithms nested
  under inspection windows. Paths retain each window's scope; values remain
  literal observations without claiming qualified native semantics.
- Source-bound window/pad tuple comparisons, including exact selected Master
  scope, pad module/block ambiguity and decimal coordinate comparisons. The
  review shows these observations and exports their raw evidence. Literal ID
  joins and a separate PartNo/CAD-ID experiment do not establish pad ownership.
- A source-bound inspection review queue in Review handoff after intake. Every observed
  selected Master window and nested algorithm is retained once, with literal
  shared-Master links to placement records. Missing/ambiguous scopes stay visible;
  no selected Master means unknown workload, not zero. Offline geometry/binding
  review and Eagle/Athena teaching checks remain separate unresolved tasks. The
  JSON queue is recomputed when reopening a saved project.
- Source-bound accounting for every selected-job CAD row and otherwise unmatched
  native placement. Duplicate reference groups remain groups, with no automatic
  survivor or enablement decision. Missing, repeated and malformed values remain
  visible. Shared blockers reference the affected rows once.
- Coordinate triage compares each placement's ROI with its stored placement
  center, separately from center/ROI versus uniquely corresponding native CAD.
  Exact decimal differences retain the source paths and raw values. Repeated
  nonzero offsets across distinct references in one uniquely identified module
  are grouped as evidence for shared-cause review, not separate defect/repair
  tasks. One shared frame-qualification prerequisite remains. Ambiguous CAD/part correspondence is not
  selected, and missing/repeated/unsupported coordinates stay unknown. These
  comparisons do not establish common frames, physical defects or repair
  eligibility; no Master-local/window coordinates or external CAD are treated as
  registered by this check. Legitimate off-center origins must be preserved.
- CSV and JSON accounting exports, and accounting in the review handoff. Source
  representation, native preparation, teaching, enablement, verification and
  release are separate; unknown states do not count as completed preparation.
- Whole-project save/reopen for original/returned archives, explicit selections,
  placement/Gerber bytes and settings, notes and target-version text. All embedded
  hashes are checked before replacing state; archive preflight and derived
  results are recomputed. Legacy source-review files remain readable.
- A bounded ACCEL ASCII source-layout reader and synthetic tests. This is a
  worker capability, not an integrated PCB upload or an Eagle coordinate adapter.
- A restricted [qualification trial writer](qualification-trials.md) in the Python
  worker. It applies accepted exact scalar proposals to a separate complete
  archive and verifies all other member payloads. It is not exposed as a repair
  button and does not independently interpret proposal evidence.

Project annotation arrays can preserve source-bound notes about decisions,
candidate history and machine observations. They are not reviewed exact-change
decisions, native candidates, or verified machine evidence. The full proposal,
approval and evidence workflow remains to be implemented.

## Supported output route and remaining work

The selected existing job, with all required companions, is the base for the
future copy-only native writer. The currently supported download preserves the
original archive and review evidence. It applies no native changes. Its outer
ZIP is transport, not a claim about what Eagle imports.

The next native milestone is one independently justified local correction with
its dependent bindings, exact scope, protected-field checks, explicit acceptance
and a separate candidate. It must survive an actual Eagle open/save/reopen before
that operation and build can be called compatible. A passing local correction
does not establish whole-board preparation or optical verification.

Engineering still required: qualified native coordinate and pad semantics,
complete dependency resolution, independent geometry diagnoses, durable exact
proposals/decisions in the application, integration of the restricted writer,
full intended-population reconciliation, detailed teaching tasks, visual evidence
and candidate history integrated into project restore, and a versioned release
handoff. Unsupported operations remain blocked.

## Evidence required from the target workflow

Record the Eagle application build and machine identity; XML format-version text
does not identify the installed application. Preserve a successful original
open, a no-intentional-edit save/reopen, and a separate copy with one documented
local operator correction. These establish normal serialization changes and the
scope/meaning of the fields under test. Compare geometry and unaffected teaching,
then test the equivalent SCAN candidate's open/save/reopen. Fresh-board optical
checks and release remain distinct, per machine.

A restricted qualification-only trial output may be used once independently
supported changes are explicitly accepted. It must be isolated and clearly
labeled; it is not a released production job. The worker now supports that
mechanical trial route; normal native export remains unavailable.

Pre-arrival placement/Gerber/BOM preparation remains part of the design. It can
connect to a later scanned job; fully scan-free native generation is deferred.

Private acceptance material is an evaluator, never an analyzer answer source.
Freeze original-input results before comparing expected outcomes. Keep all real
files, identities, geometry and detailed comparisons outside this public repo.
